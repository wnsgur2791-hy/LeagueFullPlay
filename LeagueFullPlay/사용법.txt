=====================================================
 리그 풀플레이 사용법
 (컴투스 프로야구 V26 리그모드 직접플레이 자동 진행)
=====================================================

■ 이 프로그램이 하는 일
  창 위쪽에서 [풀플레이] 또는 [하이라이트]를 고르고 시작하면 됩니다.

  [공통]
  - 리그 메인 화면이면 PLAY BALL → 고른 방식의 카드 선택 → START 를 누릅니다.
    (하늘색 테두리로 고른 카드가 선택된 걸 확인한 뒤에 START를 눌러요.
     빠른 진행으로 잘못 들어가지 않아요.)
  - 경기가 끝나면 [다음] → [다음] → [한 번 더 하기] 를 누르고 반복합니다.
  - 빈 곳을 계속 눌러서 컷씬을 넘깁니다.
    (리그 메인과 플레이 방식 선택 화면에서는 아래 '뒤로가기'가 눌리지 않게
     빈 곳을 누르지 않아요.)
  - 볼이 떨어지거나 리그가 끝나서 모르는 화면이 2분 동안 계속되면
    화면을 저장하고 알림음과 함께 멈춥니다.

  [풀플레이]
  - 투구 화면이 나오면 [포수 리드]를 누릅니다.
  - 코치의 조언(투수 체력 저하) 팝업이 뜨면 [교체]를 누릅니다.
  - 투구가 OFF로 되어 있으면 ON으로 바꿉니다.
  - 자동 타격 중에 보이는 미션 게이지에서 135칸에 체크가 생기면
    일시정지 → 시뮬레이션 전환 → 확인 을 누릅니다.

  [하이라이트]
  - 경기 화면이 나오자마자 오른쪽 아래 일시정지 → 시뮬레이션 전환 → 확인 을 누릅니다.
  - 하이라이트 직접 플레이 화면(건너 뛰기 / PLAY BALL)이 나오면 [건너 뛰기]를 누릅니다.


-----------------------------------------------------
 1단계. 파이썬 설치 (처음 한 번만)
-----------------------------------------------------
  파이썬은 이 프로그램을 돌려주는 실행 도구예요.

  1) 인터넷 브라우저에서 https://www.python.org/downloads/ 에 들어갑니다.
  2) 노란색 [Download Python 3.xx] 버튼을 눌러 설치 파일을 받습니다.
  3) 받은 파일을 실행하면 설치 창이 뜹니다.
     ★ 아주 중요: 창 맨 아래의 "Add python.exe to PATH" 칸에 꼭 체크하세요.
  4) [Install Now] 를 누르고 끝날 때까지 기다린 뒤 [Close] 를 누릅니다.

  (이미 파이썬이 깔려 있다면 이 단계는 건너뛰세요.)


-----------------------------------------------------
 2단계. 프로그램 받기
-----------------------------------------------------
  1) 받은 컴프야매크로.zip 파일을 마우스 오른쪽 버튼으로 누르고 [압축 풀기]를 누릅니다.
     (zip이 없으면 https://github.com/wnsgur2791-hy/LeagueFullPlay 에서
      [배포용 zip 받기] 링크로 받을 수 있어요.)
  2) 풀린 '컴프야 매크로' 폴더를 원하는 곳(바탕화면, 문서 등)에 둡니다.
     그 안에 '컴프야 매크로.bat' 과 LeagueFullPlay 폴더가 있으면 준비 끝이에요.
     ★ 두 개는 항상 같은 폴더에 같이 있어야 해요. bat 파일만 따로 옮기지 마세요.
       (바탕화면에서 바로 켜고 싶으면 bat 파일을 오른쪽 클릭 → [바로 가기 만들기]로
        만든 바로 가기를 옮기면 돼요.)


-----------------------------------------------------
 3단계. LDPlayer 준비
-----------------------------------------------------
  1) LDPlayer를 켜고 컴프야V26을 실행합니다.
  2) LDPlayer 오른쪽 메뉴의 [설정(톱니바퀴)] → [기타 설정] →
     [ADB 디버깅]이 "로컬 연결 허용"으로 되어 있는지 확인합니다.
     (ADB를 쓰는 다른 프로그램을 써봤다면 이미 되어 있을 거예요.)
  3) 해상도는 세로 9:16 비율(예: 900x1600, 1080x1920)이면 됩니다.


-----------------------------------------------------
 4단계. 프로그램 실행
-----------------------------------------------------
  1) '컴프야 매크로' 폴더 안의 '컴프야 매크로.bat' 을 더블클릭합니다.
     - 처음 한 번은 까만 창이 뜨고 필요한 부품(opencv, numpy)을
       자동으로 설치합니다. 1~2분 기다리세요.
     - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행] 을 누르세요.
  2) "리그 풀플레이" 창이 뜨면 성공입니다.
     (까만 창은 프로그램이 켜져 있는 동안 같이 떠 있어요. 닫지 마세요.)


-----------------------------------------------------
 5단계. 연결 확인과 인식 테스트 (처음에 꼭 해보세요)
-----------------------------------------------------
  1) [연결 확인] 을 누릅니다.
     → 위쪽에 "emulator-5554 (900x1600)" 처럼 나오면 연결 성공이에요.
  2) 게임에서 아래 화면들을 띄워 놓고 각각 [인식 테스트] 를 눌러보세요.
     인식 테스트는 화면을 보기만 하고 아무것도 누르지 않아요.
       - 투구 화면 (포수 리드 버튼이 보이는 화면) → '투구'
       - 자동 진행 중 미션 게이지가 보이는 화면 → '경기 진행(게이지 보임)'
       - 일시정지 메뉴 → '일시정지 메뉴'
       - 경기 결과 / MVP 보상 / 라운드 결과 화면
     로그에 "'투구' 으로 판단" 처럼 맞게 나오면 정상입니다.
     다르게 나오면 그 화면이 captures 폴더에 저장되니, 그 사진을 보내주세요.


-----------------------------------------------------
 6단계. 자동 진행 시작
-----------------------------------------------------
  1) 창 위쪽에서 플레이 방식(풀플레이 / 하이라이트)을 고릅니다.
     리그 메인 화면, 플레이 방식 선택 화면, 경기 중 어디서든 [▶ 시작] 을 누르면 돼요.
  2) 원하는 경기 수만 돌리고 싶으면 시작 전에 "최대 경기 수"에 숫자를 적으세요.
     0 이면 볼이 떨어지거나 리그가 끝날 때까지 계속합니다.
  3) 멈추고 싶으면 [■ 정지] 를 누릅니다.
  ※ 진행 중에는 LDPlayer 창을 최소화해도 되지만, LDPlayer를 끄면 안 돼요.


-----------------------------------------------------
 문제가 생기면
-----------------------------------------------------
  - 엉뚱한 곳을 누르거나 멈춰 있으면: 그 상태에서 [화면 저장] 을 누르고
    captures 폴더의 사진과 logs 폴더의 오늘 날짜 로그 파일을 보내주세요.
  - "adb.exe를 찾지 못했어요" 창이 뜨면 [예]를 누르고, LDPlayer 설치 폴더
    (보통 C:\LDPlayer\LDPlayer9) 안의 adb.exe 를 골라주세요. 한 번 고르면 기억해요.
  - 135 달성을 못 알아채면: config.json 에 { "gauge_yellow_min_px": 30 } 처럼
    적어서 기준을 낮춰보세요. (인식 테스트 로그에 노란 픽셀 수가 나와요.)


-----------------------------------------------------
 신고·건의 (고장이 났거나 바라는 점이 있을 때)
-----------------------------------------------------
  [실행] 탭의 [신고·건의] 버튼을 누르면 개발자에게 바로 보낼 수 있어요.
  - 고장 신고: 무엇이 잘못됐는지 적고 [보내기]. 최근 로그와 지금 게임 화면 사진이
    같이 가요. (사진에 게임 닉네임이 보일 수 있으니, 싫으면 체크를 끄세요)
    프로그램 버전·플레이 방식·해상도·현재 화면 판단은 자동으로 같이 가요.
  - 건의: 적은 글만 보내요.
  - 이름은 적지 않아도 돼요. 한 번 보내면 30초 뒤에 다시 보낼 수 있어요.
  - 고장은 이상한 화면이 떠 있을 때 바로 보내주시면 고치기 가장 쉬워요.


-----------------------------------------------------
 고급 설정 탭 (버튼을 못 찾거나 엉뚱한 곳을 누를 때)
-----------------------------------------------------
  일치도 = 화면의 그림이 버튼 그림과 얼마나 닮아야 '찾았다'고 볼지 정하는 기준이에요.
  1) 문제가 되는 게임 화면을 띄워 놓고 [지금 화면 점수 보기]를 누릅니다.
     항목마다 지금 화면의 점수가 나와요. (초록색 = 찾음, 회색 = 못 찾음)
  2) 그 화면에 분명히 있는 버튼인데 회색이면 → 그 항목의 일치도를 점수보다
     조금 낮게 바꿔요. (예: 점수 0.71 이면 일치도를 0.68 로)
     없는 버튼인데 초록색이면 → 일치도를 점수보다 조금 높게 바꿔요.
  3) [저장]을 누르면 바로 적용돼요. 진행 중이어도 괜찮아요.
  - [모두 기본값으로]를 누르면 처음 값으로 돌아가요.
  - 바꾼 값은 업데이트해도 그대로 남아요.


-----------------------------------------------------
 자동 업데이트
-----------------------------------------------------
  - 컴프야 매크로.bat 으로 켤 때마다 새 버전이 있는지 확인하고, 있으면 바뀐 파일만 받아서
    자동으로 바꿉니다. 까만 창에 "새 버전 v1.x.x을 받는 중..." 이 잠깐 보여요.
  - 내 설정(config.json), logs, captures 폴더는 그대로 남아요.
  - 프로그램을 켜 둔 상태에서는 [업데이트 확인] 버튼으로 받을 수 있고,
    껐다가 다시 켜면 적용돼요.
  - 새 버전이 켜지다가 문제가 생기면 다음에 켤 때 이전 버전으로 자동으로 되돌려요.
    (이전 버전은 업데이트백업 폴더에 있어요)
  - 자동 업데이트를 끄고 싶으면 [켤 때 자동 업데이트] 체크를 해제하세요.


-----------------------------------------------------
 세부 설정 (고칠 일이 거의 없어요)
-----------------------------------------------------
  기본 설정은 app\config_default.json 에 있고, 바꾼 값만 config.json 에 저장돼요.
  바꾸고 싶으면 config.json 을 메모장으로 열어서 아래처럼 적으면 됩니다.
    예) { "neutral_tap_interval_sec": 1.0 }

  neutral_tap_interval_sec   빈 곳 탭 간격(초). 기본 0.7
  neutral_tap_point          풀플레이 빈 곳 탭 위치 [가로, 세로] (768x1366 기준 좌표)
  neutral_tap_point_highlight
                             하이라이트 빈 곳 탭 위치 (기본: 화면 위쪽 경기장 그림)
  pause_neutral_tap_during_sim_switch
                             시뮬레이션 전환 중(일시정지~확인)에는 빈 곳 탭을
                             잠깐 멈출지 여부. true 권장
  stuck_timeout_sec          모르는 화면이 몇 초 계속되면 멈출지. 기본 120
  pitch_cooldown_sec         포수 리드를 다시 누르기까지 최소 간격(초)
  gauge_yellow_min_px        135 체크로 볼 노란 픽셀 수. 기본 60
